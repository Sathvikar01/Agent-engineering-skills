# Sathvik — Agent Engineering Skills

A framework-agnostic collection of global skills for designing, building, evaluating, and operating AI agents. The 19 skills cover architecture, development workflow, tools, structured outputs, authority, evidence provenance, state, approvals, security, recovery, observability, testing, prompts, retrieval, cost, and guardrails.

See [AGENT-ENGINEERING-SKILLS.md](AGENT-ENGINEERING-SKILLS.md) for each skill's purpose, triggers, non-triggers, relationships, files, and recommended build flow. Each skill includes behavioral and trigger eval cases. The [`evaluation/`](evaluation/README.md) directory contains the complete archived run evidence and explains how to read the results. [VALIDATION-REPORT.md](VALIDATION-REPORT.md) records the collection audit, preserved failures, installation checks, and remaining verification gaps.

The selected behavioral comparison recorded 116/116 assertions for revised skills versus 111/116 for their baselines across 68 paired runs. The trigger-selection proxy scored 379/380. Actual automatic activation, repeated-run variance, and human review remain unverified; see the validation report for scope and limitations.
